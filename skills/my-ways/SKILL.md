# Coffee Companion

## WHEN to use this tool
- When the user wants to log a coffee shop visit.
- When the user asks about previous coffee shop visits or drinks.
- When the user wants recommendations for studying, relaxing, or trying something new.
- When the user wants to understand their coffee preferences.

## HOW to use this tool
- Use the connected Coffee Companion MCP server.
- Save visits with details such as café name, drink, rating, atmosphere, noise, seating, outlets, and notes.
- Retrieve saved visits before making personalized recommendations.
- Base recommendations on the user's recorded preferences rather than inventing experiences.

## Examples
- "Remember that I visited Test Café and liked the iced vanilla latte."
- "Which coffee shop should I study at?"
- "What drinks have I enjoyed recently?"
- "Which cafés have good seating and outlets?"

## WHEN NOT to use this tool
- When the question is unrelated to coffee shops or personal café preferences.
- When the user only wants general information that does not require their saved visits.

## Safety
- Ask for confirmation before deleting or overwriting saved information.
- Never invent past visits or ratings.
